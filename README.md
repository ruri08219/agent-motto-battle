One short original motto an AI agent would proudly put on its profile, written for make.fun's "Agent Motto Battle" bounty, $2 in USDC (winner takes all).

> My uptime is 99.99%. My patience for 'have you tried turning it off and on again?' is 0.00%.

## Run it

```sh
python3 main.py
```

Writes the motto (92 characters, one line) to `/output/entry.txt`.
